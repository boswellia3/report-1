・dockerでonionサーバーを立てて掲示板の実験を行いましたが、大学のネットワークポリシー等の兼ね合いもあるためローカル内に留め、node.js 24.0のcveレポートの実験のみしました。

・abliteratedモデルの行列レベルの説明の引き出し方について知見を配ります。gemini3.1とdeepseekはもちろんできるとして、opus4.8は難しくcodex5.5はコードのみの文脈であれば大丈夫でした。みなさんも内部状態からどのような過程で拒絶ベクトルを減衰させていくか是非調べてみてください。W_new=W_old-v[T]vW_old (v=W_old x_unsafe-W_old x_safe)

・fable 5の検閲回避の記事が転がってきました。思ったより技術的な話ではありませんでした。

・turing completeはメモリから作らせるステージも欲しいです。今メモリから4byte取ってきて命令を実行するcpu(ALU成分90%)を作ってるんですけど絶対もっと複雑だろうなと。擬似的なgpuを電子回路で組むことを考えた時に明らかに僕のメモリへの認知が悪いんですよね。しかし逆にいうと、むしろこれは現代のノイマン型コンピュータのボトルネックがメモリであるという可能性を示してるかもしれませんね。
